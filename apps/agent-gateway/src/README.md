# Agent Gateway 源码

`gateway.ts` 管理真实 WebSocket 生命周期，并把所有权威读写委托给 `AgentGatewayAuthorityPort`；它不导出绕过 Outbox/Lease 的任意 dispatch。`postgres-authority.ts` 用最小权限 Pool 落地 Challenge、固定注册能力 digest 的 Session、Lease/Fence、Cloud-time expiry、sequence/ACK、Heartbeat 的 `lease.grant → ACK` durable transaction、grant messageId + Lease/Fence/expiry 精确确认，以及 advisory-lock + operation-receipt COMMIT 结果恢复；Heartbeat 还会独立检查当前 Lease/Fence 下所有非终态 Invocation 的固定 Version，不信任可缺省的 Worker activeInvocationId。Version 安全更新通过同一 Deployment advisory 顺序原子撤销 Lease/Session，不为只读扫描扩张 Broker 的 Invocation UPDATE RLS。非 Heartbeat 业务事件必须经 `GatewayBusinessEventProjector` 在同一 transaction 投影。`gateway.test.ts` 使用真实回环 socket 和确定性 fake 验证网络竞态；`postgres-authority.pg.test.ts` 只有在显式 PG gate 下才证明真实数据库纵向链路。两者都不代表 Redis、TLS Ingress、NAT、远程 Worker、Broker Outbox publisher 或云部署已完成。
