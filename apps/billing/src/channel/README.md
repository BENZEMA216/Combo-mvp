# 支付渠道适配

本目录提供乐收赢扫码支付的下单、查单和通知验签。协议实现继承主仓 `7f5fce8c` 的 Authoring 适配器，但独立于旧钱包和业务恢复模块，不访问旧计费表。

- `types.ts` 定义渠道请求、结果和固定错误类型。
- `signer.ts` 按乐收赢协议生成和验证签名，只暴露不含密钥的事件摘要。
- `gateway.ts` 使用固定 Test 或 Production 基址，检查签名、商户、原支付流水、金额和支付类型；超时或畸形响应只能查询原订单，不能自动重新下单。
- `index.ts` 导出上述端口。

调用方是 Billing 支付订单服务。机构密钥只存在于 Billing 进程内存，不交给 SDK、Agent 或 Host，也不写入订单或日志。该目录本身不启动网络请求、不选择运行环境，也不表示已接入或验证真实支付。
