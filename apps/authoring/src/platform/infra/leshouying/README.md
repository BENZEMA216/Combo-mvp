# platform/infra/leshouying — 乐收赢支付适配

这个目录实现余额充值所需的最小支付网关端口。业务模块只能调用类型化的下单、查单和通知验签方法，不能传入任意网关地址，也不能接触机构密钥。

## 文件

- `types.ts` 定义支付网关端口、规范化支付状态、带强制有效期的支付动作和固定错误类型。
- `signer.ts` 实现通用参数串拼接、MD5 签名、常量时间验签和低敏事件指纹。
- `gateway.ts` 把 H5、聚合码、支付查单和交易通知映射到乐收赢协议。测试与正式基址由枚举固定，HTTP 请求没有自动重试；响应体按流读取且最多接收 64 KiB，随后必须验签并核对订单字段。非法签名参数只形成固定类型的安全拒绝；H5 地址与聚合码内容只在本地限定时间内回读。
- `index.ts` 是本适配器的公开出口，并根据已经校验的环境配置构造真实或禁用网关。

## 上下游

`platform/infra/index.ts` 构造网关并注入 Fastify。`modules/billing/` 依赖这里的端口，不依赖乐收赢的原始字段。配置来自 `platform/config/env.ts`；机构密钥只保留在 API 进程内存中用于签名，不写入数据库、响应或日志。
