# GitHub 开源协作权威来源

- [Git 工作树官方文档](https://git-scm.com/docs/git-worktree)：工作树创建、分支占用限制，以及 `remove`、`prune`、`lock`、`move` 和 `repair`。
- [GitHub：受保护分支说明](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches)：必需检查、严格更新、审批、解决讨论和禁止绕过等规则。
- [GitHub：拉取请求评审说明](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/reviewing-changes-in-pull-requests/about-pull-request-reviews)：评论、批准、请求修改和重新评审行为。
- [GitHub：拉取请求说明](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests)：来源分支到目标分支的协作模型。
- [GitHub：使用派生仓库协作](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks)：派生仓库、`upstream` 远端、同步和允许维护者修改。
- [GitHub：从派生仓库创建拉取请求](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request-from-a-fork)：规范上游基线与派生仓库比较分支的拉取请求流程。
- [GitHub Actions：安全使用参考](https://docs.github.com/en/actions/reference/security/secure-use)：不可信输入、最小权限，以及高权限工作流执行派生仓库代码的风险。
- [约定式提交 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/)：提交类型、作用域、破坏性变更和脚注。
- [Codex：工作树](https://learn.chatgpt.com/docs/environments/git-worktrees)：托管工作树、分离头指针、会话交接、分支限制与自动清理。
- [Codex：构建技能](https://learn.chatgpt.com/docs/build-skills)：仓库级 `.agents/skills`、隐式触发与技能元数据。
- [Codex：使用 AGENTS.md 自定义说明](https://learn.chatgpt.com/docs/agent-configuration/agents-md)：仓库说明发现、优先级和新会话加载行为。

使用这些资料确认通用机制；实际命令、必需检查、审批人数和合并策略必须以当前仓库文件和 GitHub 规则为准。
