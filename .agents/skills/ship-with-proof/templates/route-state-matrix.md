## State checklist per page

- [ ] Loading state shows meaningful progress.
- [ ] Empty state gives a useful next action.
- [ ] Success state has an explicit next destination.
- [ ] Failure state says what is preserved and how to recover.
- [ ] Anonymous, owner, and non-owner permissions are defined.
- [ ] Refresh restores the same entity and stage.
- [ ] Browser back does not corrupt saved work.
- [ ] Every visible button has an implemented outcome.
- [ ] Internal terms are translated into user-goal language.
